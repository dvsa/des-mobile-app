Stop-drive order in effect Please be aware that a 'stop-drive' order has been issued by Citroën for some C3, C4, DS3, DS4 and DS5 models.

If a car is presented to use on test that you think might be included you must:
  • Use the Citroën safety recall online check to see if the car is affected by inputting the VIN number

  • The link can be found here: Citroën safety recall checker

  • If the repair work has been carried out, you must take the car on test as normal

  • If the repair work has not been carried out, you must not take the car out on test
DES has also been updated to allow you to check this while on the waiting room to car screen. Ok
