Data in examiner records This feature is for test planning purposes only and is not intended for performance management. These figures will differ from RSIS/Power BI as some test types and outcomes are not included. What’s included? These figures are based on completed tests with a successful or unsuccessful outcome. The following activity codes are included:
  • Pass (code 1)
  • Fail (code 2)
  • Eyesight fail (code 3) except in the emergency stops chart
  • Public safety fail (code 4)
  • Candidate chose to stop (code 5)
 What’s not included? Extended tests and terminations are not included. Ok
