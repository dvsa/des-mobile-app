Data in examiner records Close This feature is for test planning purposes only and is not intended for performance management. These figures will differ from RSIS/Power BI as some test types and outcomes are not included. What’s included? These figures are based on completed tests with a successful or unsuccessful outcome. The following activity codes are included:
  • Pass (code 1)
  • Fail (code 2)
  • Eyesight fail (code 3) except in the emergency stops chart
  • Public safety fail (code 4)
  • Candidate chose to stop (code 5)
 What’s not included? Extended tests and terminations are not included. Emergency stops (Cat B Car Tests) The current target % of tests with an emergency stop is 14% (1 in 7 tests)
Prior to 3rd November 2025, the target was 33% (1 in 3 tests)
